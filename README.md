# 大学物理实验计算工具

大学物理实验网页计算器，包含刚体转动惯量、电桥、电表改装、导热、RLC、声速、光栅、杨氏模量、电子荷质比、密里根油滴等实验，以及 LabVIEW 操作教程。

当前页面版本：**6.7.3**。

## 使用与部署

`index.html` 是入口。网页计算和公式排版在浏览器内运行；图表使用页面中引用的 Chart.js。将本仓库文件放入网站根目录，保留文件名与相对目录即可部署。

GitHub Pages 可以托管静态页面和计算功能，但不能运行 PHP；图片填表和用户反馈需要部署到支持 PHP 的服务器。

## 图片识别配置

`api/config.php` 只从服务器进程的环境变量读取配置，仓库中不保存实际 API Key：

| 环境变量 | 用途 | 默认值 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 图片识别服务密钥 | 空，未配置时禁用识别 |
| `DEEPSEEK_MODEL` | 服务模型名称 | `deepseek-flash` |
| `LAB_IMAGE_IMPORT_INTERVAL` | 同一 IP 的请求间隔，秒 | `60` |

请通过服务器管理面板或进程环境配置 `DEEPSEEK_API_KEY`，并确保 PHP-FPM / Web 服务能读取它。不要将密钥写进 HTML、JavaScript、PHP 配置、`.env` 或提交记录。PHP 还需启用 `curl` 和 `fileinfo` 扩展。

打开 `api/image-extract.php` 可查看是否已配置、接口是否可用；响应不会返回密钥。更换密钥后按服务器环境变量配置方式重载 PHP 服务。

## 用户反馈

反馈由 `api/feedback.php` 写入 `api/feedback-data/`。该目录需要服务器写入权限，实际反馈、联系方式、限频和锁文件均不纳入 Git。部署或更新时保留服务器上已经存在的反馈数据。

## 仓库范围

仅包含正式站点页面、页面引用的说明图、前端依赖和 PHP 接口。个人原始测量照片、教材全文、个人实验报告、备份、日志、反馈记录和 Python 本地示例不上传。
