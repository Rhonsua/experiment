① 实验原理与参数

按实际黑板要求处理；《大学物理实验教程》第 191～196 页辅助，采用式（3-4-10）～（3-4-12）。忽略空气浮力，计算电荷量的大小。教材的 3 次重复改为课堂要求的 5 次；密度按黑板取 979 kg/m³。

vf=ℓt¯ r0=9ηℓ2ρgt¯
q=18π2ρg⋅[ηℓt¯(1+bpr0)]32⋅dU¯
n=round(qe0) e=qn e¯=e1+e2+e3+e4+e55
每颗油滴先取 5 次的 Ū、t̄，再计算 q；修正项用未修正半径 r₀（教材近似）。n 为最接近 q/e₀ 的整数，不是油滴编号。e₀ 默认使用黑板的 1.602×10⁻¹⁹ C；此方法是元电荷验证，不能据此独立发现电荷量子化。

d、ℓ 输入 mm，程序换成 m；p 与 b 必须配套使用 Pa、Pa·m。g、η、p、b、d 的默认值取教材第 193 页；p 为标准气压，若有实测值请替换。表中结果显示 4 位有效数字，平均和取整均使用未舍入值。

课堂操作、原理与注意事项
  1. 调平仪器，连接电源与成像系统；喷雾后调焦，选择清晰且较稳定的油滴。
  2. 按任意键 → 确认 → 喷雾 → 工作，调平衡电压，使油滴稳定悬浮，记录 U。
  3. 提升至 0 线以上 → 平衡 → 0 V；到 0 线按开始，到 1.6 线按结束，记录匀速下落时间。
  4. 同一颗油滴重复 5 次并确认数据，再按重做换下一颗；共测 5 颗，每次测量前重新核对平衡电压。

平衡时电场力与重力相等；撤去电场后，匀速下落时黏滞阻力与重力平衡。先按斯托克斯公式求 r₀，用 r₀ 代入滑移修正项求 q。上方及下方的完整计算过程给出对应公式。

喷雾器使用后口朝上放入杯中；关机前将电压调到零。避免接触电极，保持仪器水平；正式计时应避开开始加速段。
