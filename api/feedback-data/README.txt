用户反馈文件保存在这个目录。

每个月一个文件，例如 feedback-2026-10.txt.php。
通过 FTP 下载后，用记事本或其他文本编辑器打开即可查看。
文件第一行是网页访问保护代码，后面每一个 JSON 段落是一条反馈。
时间使用北京时间；联系方式是用户选填的内容。

不要在服务器上把反馈文件改名为 .txt、.json 或 .html；保留 .php 结尾及第一行保护代码。
网页访问这些文件不会显示反馈，FTP 下载不受影响。
feedback-state.php、feedback-lock.php 是防重复与限频的内部文件，不是反馈记录。
后续更新功能时不要覆盖、清空或删除已有反馈文件。
